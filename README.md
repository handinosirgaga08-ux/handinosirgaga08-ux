# Hi, I'm Sirgaga Handino 👋

Economist and software developer from Ethiopia, building digital tools for local government and community organizations.

## What I'm building

**Shashogo Woreda Integrated Digital System (SWIDS)**: an e-government platform that connects woreda sector offices and rural kebeles for online reporting, performance evaluation and citizen services.

- Amharic and English interface
- Installable as a PWA, works on phones
- Deployed on Render, published as a package on GitHub Packages
